One image of a letter inviting the AI judge to come and visit my house. It is a proper paper invitation — "Dear AI Judge," on cream paper with a little house, chimney smoke and sun in the corner, a red wax seal, and a postscript that winks at the fact that a judge model cannot literally visit: "the invitation is the visit." The kettle is already on, there is an armchair by the window with the judge's name on it, and no calculations are required. `main.ts` writes the 1024×1024 PNG to `/output/entry.png`, where the competition's gate scorer reads it. The image is drawn by `draw_letter.py` (Pillow, no network, deterministic).

## Run it

```sh
node main.ts
```
